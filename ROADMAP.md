# Roadmap del Portal IT / Sistemas

## Fase 1: Núcleo Operativo (Completado)
- [x] Configuración inicial de arquitectura React + TypeScript + Tailwind + Firebase.
- [x] Autenticación y gestión de roles (`admin` Jefe de Sistemas y `analyst` Analista IT).
- [x] Layout principal con Sidebar colapsable, Header, Búsqueda global, Notificaciones y Modo Oscuro/Claro.
- [x] Command Palette (`Ctrl/Cmd + K`) y atajos de teclado (`C`, `T`, `I`, `M`, `P`, `/`).
- [x] Módulo completo de Tareas y Pendientes con vistas Lista, Kanban, Calendario, Agenda y Tabla.
- [x] Módulo de Proyectos de infraestructura y desarrollo.
- [x] Módulo de Incidencias y Soporte con semáforo SLA.
- [x] Módulo de Calendario y Reuniones centrales IT con generación de tareas desde acuerdos.
- [x] Base de Conocimiento y Documentación técnica estilo Notion.
- [x] Inventario de Activos Tecnológicos.
- [x] Control de Compras, Licencias, Dominios, SSL y Renovaciones con alertas.
- [x] Gestor de Archivos y Recursos.
- [x] Bitácora de Auditoría inmutable.
- [x] Seed inicial de datos reales para el Departamento de Sistemas.

## Fase 2: Automatizaciones y Notificaciones Push
- [ ] Implementación de Cloud Functions para notificaciones automáticas por correo electrónico.
- [ ] Integración de Webhooks para alertas de monitoreo (Zabbix, Nagios, UptimeRobot).
- [ ] Recordatorios PWA y notificaciones Push del navegador mediante FCM.

## Fase 3: Integraciones Avanzadas y Métricas
- [ ] Integración con proveedores de correo transaccional (SendGrid / SMTP corporativo).
- [ ] Exportación de reportes ejecutivos en PDF/Excel para gerencia general.
- [ ] Extensión del sistema a un portal de autoservicio para usuarios finales de la empresa.
